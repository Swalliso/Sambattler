# Ideas

Ideas that aren't adopted, written against [SPEC v2](../../SPEC.md). Each idea gets its own file here. It:
- names the spec sections it touches;
- marks what's measured and what's a guess;
- is discussed with the user before anything is built from it (CLAUDE.md).

When the user adopts one, it goes into SPEC, and its file stays as the reasoning behind it.

Ideas written for the v1 battle are archived in `docs/archive/v1/ideas/`, listed in [the archive's README](../archive/README.md). They're history, not open proposals. Research on other games is in [docs/research/](../research/README.md).
