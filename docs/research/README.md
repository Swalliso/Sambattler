# Research

Web research on other games. It sits outside the [archive](../archive/README.md) because it still applies under [SPEC v2](../../SPEC.md).

The reports were written for the after-the-rework review on 2026-10-31, before v2. What they found about other games holds. The parts that apply it to Spore & Sprawl were written for the v1 battle, so check them against SPEC v2 before you use them:
- **research-one-more-run-and-feel.md:** §1 (our problems, P1–P10), the "For us" paragraphs in §2, and §4–§5;
- **research-autobattler-roguelites.md:** §1 (D1–D12, C1–C5), §4 and §5;
- **research-lane-battlers.md:** "What the repo already covers", "The problems this research is aimed at", "Transferable mechanics" and "A suggested shortlist".

| Report | What it covers | Most useful for |
|---|---|---|
| [research-one-more-run-and-feel.md](research-one-more-run-and-feel.md) | Why players start another run, game feel, comebacks, tension, run length, onboarding and readable armies, from designers' own talks | R4 (readable armies), M6 (meta-progression), lives and losses |
| [research-autobattler-roguelites.md](research-autobattler-roguelites.md) | Build expression and run-to-run variety in auto-battlers and builder roguelites | R3 (augments, combos, run packs) and drafts |
| [research-lane-battlers.md](research-lane-battlers.md) | Lane tug-of-war and real-time army games, with 23 mechanics to borrow | Unit roles, counters and readability. Many of its mechanics assume a live lane, which v2's rounds replace |

Read only that section; the rest of that design is archived.
